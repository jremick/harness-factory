# ADR 0002: Evaluator outside the model-harness system

- Status: accepted
- Date: 2026-08-12

## Decision

The evaluator is a sibling component with separate source, fixtures, permissions,
and evidence output. It consumes the public evaluation contract and post-run
fixture state but is neither generated by nor editable by the generated harness.
Generated self-tests provide verification evidence only; they never constitute
the final acceptance oracle.

## Consequences

End-to-end execution needs a sandbox or allowlisted command wrapper and explicit
leakage tests. Some evaluation logic cannot be distributed with the model-visible
fixture used for a truly blind run; the repository therefore separates public and
private evaluator material and documents how to stage a clean run.
