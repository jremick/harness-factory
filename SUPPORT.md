# Support

Use [GitHub Issues](https://github.com/jremick/harness-factory/issues) for
reproducible bugs, documentation problems and narrowly scoped feature requests.
Include the Harness Factory version, Python version, operating system, exact
command, redacted output and a minimal HDP when possible.

Questions about the provider-neutral contract belong in
[`jremick/hdp-reference`](https://github.com/jremick/hdp-reference). Security
reports belong in the private channel described in [SECURITY.md](SECURITY.md).

This public alpha has no guaranteed response time and should not be relied on as
a production control plane.
